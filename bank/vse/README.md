# Банк задач přijímaček VŠE

Банк реальных задач вступительного теста по математике VŠE (Vysoká škola ekonomická v Praze) для линии VŠE. Устроен так же, как банк технических вузов в `bank/`: те же правила, поля, уровни и темы (см. [`../README.md`](../README.md)). Лежит в отдельной папке, чтобы задачи VŠE не попали в модуль банка на странице ČVUT.

Сборка: `python3 bank/build.py bank/vse`. Скрипт создаёт `tasks.site.json` (формат сайта) и `BANK.md` (обзор по уровням с ответами).

## Правила

- **Текст задачи — только оригинал VŠE.** Задачи, которые в курсе пересказаны («přeformulováno»), помечены `needs_original` (⚠) и ждут замены текстом из PDF.
- **Не берём источники с ограничениями:** Scio (тесты «для индивидуальной подготовки»), платные книги, сайты третьих сторон с неизвестными условиями.
- **Уровни 1–3; темы плана 1–35; вне плана — 0 «Ostatní».** Для VŠE сюда попадают проценты, составление выражений и средние значения.
- **Задачи, которые уже есть на сайте, остаются;** где они на сайте — в поле `in_course`.

## Что внутри сейчас

**22 задачи** из открытых образцов VŠE. Все взяты из материалов курса (лекции и ДЗ 3–12), **ответы пересчитаны заново**.

- **Vzorový test z matematiky** (FMV; те же задачи в образце FFÚ/FPH) — 5 задач: příklady 1, 11–14. Записаны дословно.
- **Vzor přijímacích zkoušek A и B** кафедры математики — 17 задач (A: 3, 4, 5, 7–12; B: 3, 5, 7–12). В курсе они пересказаны с сохранением чисел и вариантов, поэтому помечены ⚠.

Уровни: 8 базовых, 9 стандартных, 5 сложных. Покрыты темы 1, 3, 4, 6, 7, 9, 10, 12, 19 и Ostatní.

## Как сейчас поступают на VŠE (бакалавриат, 2026/27)

Правила задаёт каждый факультет:

- **NF** — только тест Scio OSP/VŠP.
- **FM** — Národní srovnávací zkoušky (NSZ) Scio.
- **FIS** — OSP/VŠP или prominutí.
- **FPH, FMV** — свои правила и prominutí. Собственный тест по математике (образцы FMV, FFÚ/FPH и KMAT A/B) по данным сторонних сайтов используют FFÚ, FMV и FPH; это нужно проверить по документам факультетов.

Ссылки на правила всех факультетов — в `sources.json` (запись `vse-podminky`).
